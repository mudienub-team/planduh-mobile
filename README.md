# PLANDUH

**Personal Learning, Activities, Notes, and Daily Utility Hub**

Aplikasi Android native untuk membantu pelajar mengatur jadwal pelajaran, tugas, dan catatan harian.

## Tech Stack

- Kotlin + Jetpack Compose (Material 3)
- [KomoUI](https://github.com/derangga/komoui) sebagai library komponen UI
- Min SDK 29, Target SDK 37
